# 交付与质量数据填写表（内部资料）

当前首页和 OEM 页保留已确认的四项信息：常规量产 40–45 自然日、100% 人工检验、正常月产 600,000 件、三个阶段的订单进度反馈。它们分别描述交期、检查方式、综合产能及沟通安排。

按最新补充要求，参考图的 **98%** 与 **<0.5%** 已加入页面，分别标为准时交付目标和产品缺陷率目标。当前没有本厂对应统计记录，未作为已验证的历史实绩发布。若要改为实际交付率／缺陷率，可补齐下列记录。

## 准时交付率

| 项目 | 请填写 |
| --- | --- |
| 统计期间 | 起止日期，例如连续 12 个月 |
| 产品／工厂范围 | 保鲜盒、锅具或全部产品；是否包括协同采购 |
| 承诺的交付节点 | 生产完成、检验完成、出厂、装船或客户收货；选定并保持一致 |
| 期间内应交付订单总数 | 分母；按订单、批次还是订单行计数 |
| 按约定节点准时完成数量 | 分子；与分母使用同一单位 |
| 变更及排除规则 | 客户改期、延期付款、部分交货等如何处理 |
| 原始记录 | 订单台账、约定日期、实际完成／发运日期、计算负责人 |
| 允许公开的口径与文字 | 是否同意公开统计期间、范围和计算口径 |

计算：**准时完成数量 ÷ 应交付总数 × 100%**。分母为零或记录不完整时不发布百分比。

## 缺陷／退货数据

| 项目 | 请填写 |
| --- | --- |
| 指标类型 | 出厂检验不良率、客诉缺陷率或退货率；不要混用 |
| 统计期间及产品范围 | 与所选指标对应 |
| 分母及单位 | 受检件数、实际出货件数或订单数 |
| 分子及单位 | 不良件、确认客诉件、退货件或涉及订单数 |
| 缺陷定义 | 哪些问题计入；返工前还是返工后统计 |
| 重复计数规则 | 同一件多种缺陷、同一订单多次客诉如何计算 |
| 抽样或全检说明 | 样本数据只代表抽样范围，不能直接作为全部出货比例 |
| 原始记录及确认人 | 检验记录、客诉台账、统计人和核准人 |
| 允许公开的口径与文字 | 是否允许公开周期、样本范围和指标名称 |

计算：**符合定义的问题数量 ÷ 对应总数 × 100%**。百分比的小数位应与样本规模匹配。

## 发布文字模板

- On-time [agreed milestone]: **[rate]%**, based on **[on-time count] of [total count] [orders / lots]** due between **[start] and [end]**, covering **[scope]**.
- **[Metric name]: [rate]%**, based on **[issue count] of [denominator] [units / orders]** during **[period]**. **[Definition / inspection scope]**.

以上是内部填写模板，不是已确认的公开声明。数据未补齐不影响浏览当前优化版本。
