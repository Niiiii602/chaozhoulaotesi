## 视频处理

| 项目 | 结果 |
| --- | --- |
| 来源 | 原官网干净工厂实拍片，保留原始文件 |
| 时长 | 33.8 秒，页面显示约 34 秒 |
| 分辨率／画幅 | 1280×420，原画幅完整保留，不追加裁切 |

| 文件大小 | 8,018,822 字节，约 7.65 MiB |
| 音频 | 原片没有音轨，保持无声，未添加音乐 |

原旧站水印属于网页叠层，本次将 MayLendy 文字直接写入视频画面，所以全屏、独立播放器及下载后的文件仍保留三处水印。静态封面继续使用已有三水印工厂封面。

制作脚本：[build_factory_video.py](../tools/build_factory_video.py)。使用本地 FFmpeg 7.1；临时工具和字体副本仅放在会话临时目录，没有安装到系统或放入网站包。成片已生成，浏览网站不需要运行制作脚本。

## 页面体验

银白风格的视频大画面配右侧制造说明；手机端上下排列，保留原画幅，支持原生全屏观看。默认不自动播放，点击“Play workshop video”启动；原生暂停、进度、全屏控件一直可用，结束后可重播。

播放器支持键盘启动和暂停，焦点从播放按钮移至播放器；切换到不可见页面时暂停。视频加载失败时显示说明和直接打开链接，可以重新加载并重试。关闭 JavaScript 时仍有原生视频控件。
