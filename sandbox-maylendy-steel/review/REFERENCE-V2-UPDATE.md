# 新版修改参考 · 第二轮落实

依据您新上传的《Maylendy官网修改参考.docx》（正文三项意见及三张配图），以及采用参考百分比的补充要求，继续修改最新 `sandbox-maylendy-steel/`。本轮仍为 23 页，没有部署线上站点。

## 1. 案例去图与客户保密

首页和 OEM 页的案例卡片已去掉产品图，改成项目编号、客户渠道、问题与结果的文字排版。两篇案例详情也去掉产品图，保留背景、处理过程与结果。

参考 [Potobelo 案例页](https://www.potobelo.com/case-studies) 的匿名原则，以 MayLendy 自有英文文案说明：客户采购关系是商业敏感信息；客户身份及交给工厂的产品开发、生产、包装等信息受到保密保护；案例只分享匿名摘要，不公开客户专属生产或包装细节。

查看：[OEM 案例区](../oem.html#projects) · [饭盒案例](../case-compartment-lunch-box.html) · [套装案例](../case-nesting-storage-set.html)。

查看：[七种盖型](../food-storage.html#lid-options) · [产品目录](../products.html) · [盖型指南](../guide-storage-lids.html)。

## 3. 首页轮播加快

自动展示从每轮约 **5.6 秒**改成约 **2.4 秒**：中心停留 0.6 秒，移动过渡 1.8 秒。下层初始错峰从 0.65 秒缩短到 0.15 秒。

本机 Chrome 实测：两层均在约 **1.735 秒**后切换到下一中心产品。上层向右、下层向左保持不变；暂停／恢复、独立按钮、键盘、触屏拖动、减少动态、离屏停止和 WebGL 回退全部通过。

- **115 组布局**：23 页 × 1440 / 1024 / 768 / 390 / 360 px，全部通过；无横向溢出、缺图或运行错误。
