# 展示数字、视频对齐与阅读层次更新

本轮继续优化最新银白版，仅修改 `sandbox-maylendy-steel/`。原官网和其他沙箱不变，页面仍为本地预览。

## 展示数字增长

产能、厂区面积和团队人数共 **17 处**加入增长动效：首次进入视区时从 0 增长至最终值，设定时长 **3,000 ms**，本机 Chrome 实测约 **3.03 秒**。

| 页面 | 参与动画的展示数字 |
| --- | --- |
| 首页 | 600,000 / 800,000 月产、20,000 / 40,000 m²；交付模块的600,000月产 |
| 制造页 | 上述四项；产能说明中的600,000 / 800,000及100+团队人数 |
| 公司页 | 四项产能和面积数字 |
| OEM页 | 交付模块中的600,000月产 |

数字进入视区后播放，离屏暂停，回来继续；完成后本次页面浏览不反复重播。千位分隔、m²及“+”保留，预留最终数字宽度以防布局抖动。

产品型号、容量、尺寸、材质、MOQ、交期、年份、检验及交付比例等固定信息维持静态显示。完整最终值写在初始HTML中；读屏保持读到最终值，关闭JavaScript、开启减少动态效果或打印时也显示完整数值。运行中切换减少动态效果会立即完成计数。

实现位于 `tools/display_metrics.py`、`countup.css` 与 `app.js`，只有包含增长数字的四个页面加载新增样式。

## 视频与右侧横线对齐

桌面布局将视频和右侧说明放在同一等高行中，视频容器顶部对齐“FILMED AT OUR FACTORY”上方横线，底部对齐操作链接下方横线。标题说明和视频字幕各自独立，不占用这一行的对齐高度。

首页与制造页在 **1440px、1024px** 下的上下边界实测差值均为 **0px**。视频保持完整原画幅，居中显示；等高容器多出的空间采用留边，不裁掉三处水印。

1000px及以下改为上下布局；窄屏播放按钮位于画面下方，与原生控件分开。播放、暂停、跳转、全屏、重播、键盘、失败重试及无脚本播放均继续可用。三水印MP4文件没有改动。

## 文字与交互层次

- 主标题加重，次级标题保持清楚区分；引导文字适度放大、提高对比，正文控制行宽与行距。
- 首页明确强调制造地、保鲜盒／锅具重点和图纸／样品OEM能力，文字事实不变。
- 小标题、段落及操作入口增加清楚的间距和层级；链接卡片提供标题下划线、箭头和边框反馈。
- 键盘焦点与鼠标悬停保持一致的操作提示；纯信息卡不伪装成可点击内容。保留减少动态和打印样式。

## 验证结果

- **26项数字动效检查**：零起点、单调增长、3秒时长、准确终值、宽度稳定、单位、读屏最终值、离屏暂停／继续、不重复播放、减少动态、无观察器回退、打印、无脚本和固定规格保护通过。
- **25项视频与对齐检查**：两个页面五档宽度、桌面上下边界、画面居中及手机按钮间距和原有播放功能通过。
- **115组全站布局**：23页 × 1440 / 1024 / 768 / 390 / 360，全部通过，无横向溢出、缺图或运行错误。
- **56项交互回归、19项双层展示与卡片检查、55项静态及链接检查**均通过。
- 52个核心型号、67条组件规格、59个目录条目保持一致；2,019个受保护文件未改动。
