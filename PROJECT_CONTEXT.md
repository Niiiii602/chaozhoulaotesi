# Chaozhou Laotesi Factory Website

This project contains the OEM factory website for Chaozhou Laotei Enterprise CO., LTD.

## Current scope
- Warm white and light sage visual system
- Factory introduction before product ranges
- Factory photo/video watermark: Chaozhou Laotesi
- Food storage container catalog modules
- Cookware modules for tri-ply, silicone glass-lid, promotional 02 series and single-layer cookware
- Products and factory assets prepared for OEM export presentation
